- Тип источника помечен так:
  - **[офиц.]** — госорган, регулятор, оператор платных дорог или нацкомпания;

## 11. «Нет надёжного источника» — список пробелов

1. **Цены на топливо: официального машиночитаемого источника нет** для Казахстана, Грузии, Абхазии, Армении (абсолютные цены), Узбекистана.
   - Для Беларуси (Белнефтехим), Кыргызстана (Госантимонополия), Азербайджана (Тарифный совет, только АИ-92/ДТ) и Турции (EPDK) источник есть, но API или CSV не найдены.
   - Цены LPG/CNG по Армении и Узбекистану, а также Абхазии целиком — **отсутствуют**.
2. **globalpetrolprices.com:** условия использования не разрешают коммерческое использование. По данным третьей стороны, лицензия CC BY-NC-ND 3.0. **Без договора для «Версты» непригоден.**
3. **Казахстан:** официальная таблица тарифов kaztoll.kz для легковых; порядок и цена ОГПО для нерезидента на границе; статус проекта повышенных тарифов для транзитных иностранцев.
4. **Координаты переходов** (Верхний Ларс, Адлер/Псоу, Бугристое, Сагарчин, Караузек, Сарпи, Садахло) — **не получены**, брать из OSM и проверять.
5. **Онлайн-очереди для легковых:** официального сервиса нет ни на одной из границ РФ (Беларусь — не нужен; Грузия и Казахстан — только для грузовых).
6. **Грузия:** официальное подтверждение отсутствия платных дорог; признание ВУ РФ и нужно ли МВУ (официальный текст); официальный прайс tpl.ge (страница не открывалась).
7. **Абхазия:** ограничения скорости, признание ВУ, официальный тариф и штраф за местную страховку, наличие сбора за въезд.
8. **Армения:** признание ВУ РФ; тарифы местного ОСАГО (appa.am); актуальность экосбора (разовый 3 750 AMD или за каждые 15 дней).
9. **Азербайджан:** тарифы платной трассы Баку–Губа; дорожный налог для иностранных ТС. Пока граница закрыта, это некритично.
10. **Узбекистан:** ставка въездной пошлины для легковых в приложении № 10 к ЗРУ-1105 (15 USD подтверждено только kdmid.ru без даты); признание ВУ РФ; скорость за городом.
11. **Кыргызстан:** срок пребывания иностранного авто по ПКМ № 688 от 12.10.2026; ОСАГО для иностранцев на границе; ограничения скорости; признание ВУ.
12. **Турция:** официальная таблица KGM; размер штрафа по Регламенту от 29.07.2026; цена пограничной страховки; срок действия ВУ РФ.
13. **Беларусь:** октябрьские цены Белнефтехима; фактический статус ОСАГО РФ с расширением на РБ в 2026 году; статус погранстраховки.
14. **Сторона движения:** везде правостороннее, отдельным источником в этой проверке не подтверждалось.

## 12. Рекомендации для бэкенда (кратко)

- **Модель данных:** каждое значение хранить с `source_url`, `source_type` (official/primary/secondary), `checked_at`, `valid_from`. Значения [втор.] в UI не показывать как факт — только с пометкой «по данным…» или вовсе скрывать.
- **Флаги статуса границ:**
  - Азербайджан — `closed_until=2027-01-02`;
  - Верхний Ларс — `seasonal_risk` (ноябрь–март);
  - Сырым (КЗ) — `closed_for_cars` до конца 2026.
- **Виньетка Беларуси:** условие `vehicle_registration ∉ ЕАЭС`. Для пользователей из РФ — 0.
- **Турция:** в чек-лист поездки добавить «HGS обязателен; долг блокирует выезд».
- **Сначала разблокировать в сетевых настройках сессии** хосты beltoll.by, belneftekhim.by, kaztoll.kz, tpl.ge, epdk.gov.tr, kgm.gov.tr, kdmid.ru, mintrans.gov.ru и повторить сверку: до этого все факты получены только из текста поисковой выдачи.

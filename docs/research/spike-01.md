# SPIKE-01: построение маршрута на лету без привязки к поставщику — результаты

27.10.2026 · Менеджер · прогон spike01 (PR #2, job 122203547057, коммит 21176be) · ADR-0021 §5

## Итог

**Делаем (go).** Построение на лету по открытым данным во всех трёх случаях дало маршрут интереснее, чем сегодняшний каталог. Для Бали каталога у нас нет вовсе, а прототип построил разумный день за 1 секунду. Платные источники нужны точечно: в «гибриде» это 3–5 ₽ на одно построение против 56–65 ₽, если брать всё у поставщика.

**Перед продакшеном нужно исправить четыре вещи** (они вошли в ARCH-01, DATA-05 и ENG-09):
1. фильтр безликих мест;
2. правило «с собакой — не в музеи»;
3. Wikidata заранее, а не в момент запроса;
4. пространственная база вместо поиска на Python.

Оценки людей (по 1–5 на каждое место) ещё нужны, чтобы перевести «на глаз лучше» в цифру.

## Что сравнивали

Три маршрута:
1. Москва → Казань, семья с ребёнком 7 лет;
2. Москва → Казань без платных дорог, двое взрослых и собака;
3. Бали: Денпасар → Убуд → Ловина, семья с ребёнком.

Условия:
- **Данные:** OSM (Геофабрик, 27.10.2026) плюс Wikidata.
- **Дороги:** наш GraphHopper.
- **Платные источники** (Яндекс, 2ГИС, Google) не подключены: юрлица нет. Их цена посчитана по прайсам.
- **Для российских маршрутов** тот же экипаж прогнан через сегодняшний движок с каталогом в приложении.

## Выводы

1. **Качество.** На лету находятся главные места по пути, которых нет в нынешнем каталоге: Владимир, Раифа, Казанский кремль. Шум даёт OSM: безликие «Городской парк» и «Краеведческий музей». Нужен фильтр: название из общих слов и ни одной ссылки в Wikidata — такое место не берём.
2. **Анкета работает,** но правил пока мало:
   - для поездок с собакой нужно понижать вес закрытых мест (музеи);
   - остановку в городе старта не стоит предлагать, если человек сам не попросил.
3. **Часы работы известны только у 33–50 % мест.** Это и есть работа платного слоя (уточнение финалистов) и наших кураторов. Без них половина остановок будет «не проверено».
4. **Скорость.** Построение занимает 1–1,7 с, из них поиск в коридоре на чистом Python — 0,8–1,5 с. С пространственной базой (PostGIS, DATA-05) это будут десятки миллисекунд. Цель ≤ 5 с выполнена с запасом.
5. **Деньги.**
   - Гибрид дешевле в 11–19 раз, чем брать всё у поставщика, но 3–5 ₽ на построение — это всё ещё больше нашего дохода, ≈ 2,9 ₽ на поездку (BIZ-01).
   - **В России** выход — годовая лицензия Яндекса или 2ГИС (фиксированная цена, хранение данных разрешено), тогда стоимость одного построения стремится к нулю.
   - **За рубежом** у Google каждый запрос платный и хранить данные нельзя, поэтому туда — только с платной подпиской («Про») или другим поставщиком.
   - Это вход для BIZ-07.
6. **Независимость от поставщика работает.** Без ключей и юрлица выбор каждый раз уходил на открытые данные, с причиной в журнале: «Яндекс: нужно российское юрлицо», «Google: нужно иностранное юрлицо». Подключить Яндекс — значит добавить ключ в настройки, а не переписывать код.

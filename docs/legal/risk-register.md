# Реестр правовых рисков «Версты»

> **Это не юридическая консультация.** Документ подготовлен аналитиком по правовым вопросам команды (не юристом). Он описывает риски, рабочие решения по умолчанию и вопросы к квалифицированному российскому юристу. Всё, что обязывает компанию, до применения проверяет юрист.

- **Дата:** 25.10.2026. **Версия:** 1.
- **Связанные документы:** [lawyer-brief-odbl.md](lawyer-brief-odbl.md) (LEG-01, DATA-01), [leg-02-checklist.md](leg-02-checklist.md) (LEG-02, черновики политики и согласия).
- **Как проверялись источники.** Из рабочей среды прямой доступ к большинству сайтов (opendatacommons.org, osmfoundation.org, consultant.ru, travelpayouts.com, rustore.ru, fips.ru) закрыт сетевой политикой. Поэтому тексты ODbL 1.0, CC BY-SA 4.0, CC0 1.0 и OFL 1.1 сверены дословно по копиям SPDX (github.com/spdx/license-list-data). Остальные источники проверены по поисковым выдержкам с указанных страниц. Где источник вторичный (блог, обзор), это сказано прямо. **Юристу: сверить каждую норму по действующей редакции** (КонсультантПлюс / pravo.gov.ru).
- **Шкалы.** Вероятность: **В** — высокая (произойдёт при текущем плане), **С** — средняя, **Н** — низкая. Тяжесть: **К** — критическая (угроза продукту, ядру данных или деньгам), **В** — высокая (штраф, блокировка, снятие из стора), **С** — средняя, **Н** — низкая.
- **Статус решения по умолчанию:** «действует» — уже соблюдается в репозитории или решениях; «с этой недели» — вводим сейчас, до ответа юриста.

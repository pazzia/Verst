# Воронка партнёров BIZ-02 / BIZ-03

Версия 1 · 26.10.2026 · Ведёт CEO после каждого касания. Partnerships сверяет раз в неделю и пишет следующий шаг.
Цели — [targets.md](targets.md); письма — [hotels-pack.md](hotels-pack.md), [regions-pack.md](regions-pack.md).

**Правила записи.**

- Без персональных данных: только организация и **роль** собеседника. Не записываем имена, телефоны, личные адреса.
- Дата — `дд.мм.гггг`.
- «Итог» заполняется, только когда этап закрыт.
- Договоры и письма о намерениях в репозиторий не кладём. Здесь пишем только факт: «LOI подписан дд.мм».

**Этапы.**

| Код | Этап | Когда этап считается достигнутым |
| --- | --- | --- |
| 0 | Не связывались | — |
| 1 | Письмо отправлено | Первое письмо ушло с адреса компании |
| 2 | Follow-up 1 | Отправлен |
| 3 | Follow-up 2 | Отправлен, дальше не пишем |
| 4 | Ответ получен | Любой ответ, кроме автоответа |
| 5 | Разговор | Звонок или встреча состоялись. **Засчитывается в приёмку BIZ-02 (≥ 5)** |
| 6 | Пилот согласован | Есть письмо о намерениях или согласованная одна страница. **Засчитывается в приёмку (≥ 1)** |
| 7 | Пилот идёт | Дата старта наступила |
| 8 | Итог пилота | Отчёт сдан, решение принято |
| X | Закрыто | «Нет», или нет ответа после follow-up 2, или вне фокуса |

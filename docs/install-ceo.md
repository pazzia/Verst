# «Верста» — установка на телефон

Демо-сборка: отели, придорожные кафе и АЗС на трассе вымышленные; достопримечательности, кафе и бары в городах,
парки — настоящие, из открытых данных. Поездки по России строятся на телефоне без интернета; поездки за границу и
режим «На сервере» — через тестовый сервер. Оплаты и настоящего бронирования нет.

1. На телефоне откройте постоянную ссылку на последнюю **тестовую** сборку (рабочая ветка, обновляется после
   каждой успешной сборки; входить в GitHub не нужно):
   `https://github.com/pazzia/Verst/releases/download/verst-test-latest/Verst-test-latest.apk`
   Сборки из основной ветки `main` (выходят после слова «Сливай»):
   `https://github.com/pazzia/Verst/releases/download/verst-latest/Verst-latest.apk`
2. Скачайте APK.
3. Откройте скачанный файл. Android попросит разрешить установку из этого источника — разрешите (только для браузера, из которого скачивали).
4. Если «Верста» уже установлена, новая версия встанет поверх; сохранённые поездки останутся. Исключение — переход с 0.2 на 0.3 (новый ключ подписи): старую версию один раз удалите.
5. Запустите «Версту». Первый запуск занимает несколько секунд: на телефоне стартует планировщик маршрутов.

## Что попробовать

- **Готовый маршрут:** на лобовом стекле выберите «Золотое кольцо» → «Поехали» → настройте экипаж → «Поехали».
- **Свой маршрут:** нажмите «Куда угодно», наберите «Ярославль», выберите город → «Поехали».
- **Дорога впереди:** «заменить» у остановки, «Выбрать отель →» у ночёвки, путевой лист внизу экрана.
- **Мои поездки:** значок закладки вверху сохраняет поездку; на лобовом стекле появится «Мои поездки». Долгое нажатие на поездку — удалить.

## Если что-то не так

- Анимаций нет — проверьте, не включено ли в настройках Android «Убрать анимации».
- Планировщик не запустился — нажмите «Повторить» на лобовом стекле.
- Служебная панель (для разработчиков): долгое нажатие 2 секунды на слово «НАВИГАТОР».

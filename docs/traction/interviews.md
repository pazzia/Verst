## 3. Темы (боли), ранжированные по частоте × интенсивности

Как считать:

- **Частота** — в скольких разговорах тема встретилась (N из всех проведённых).
- **Интенсивность** — средняя по разговорам с этой темой, шкала 1–3 из шаблона заметки
  (3 — эмоция и последствие, 2 — подробно без последствий, 1 — вскользь или по вопросу).
- **Ранг** = частота × средняя интенсивность.
- **Сам / по вопросу** — сколько раз тема всплыла без нашего вопроса. Темы, которые звучат
  только по вопросу, понижаем на одну ступень уверенности.
- **Уверенность**: высокая — 3+ независимых разговора, тема звучит без подсказки и в
  нескольких сегментах; средняя — 2 разговора, или только по вопросу, или только в одном
  сегменте; низкая — один разговор. Выводы о сегменте — только при 5+ разговорах в нём.

## 6. Три ставки: решение go / adjust / drop

Критерии записаны **до** первых разговоров, чтобы не подгонять вывод под желаемое. Пороги —
предложение UX Specialist; CEO может их изменить до 5-го разговора, после — только с
пометкой в журнале изменений.

Считаем по разговорам с поездкой 2+ дня. «Конкретный случай» — описанный эпизод из
последней или предпоследней поездки с интенсивностью 2–3, а не мнение «вообще бывает сложно».

### 6.1 Ночёвки по темпу

Гипотеза: людям трудно решить, где ночевать в пути, и они теряют на этом время, деньги или
нервы.

| | Критерий |
| --- | --- |
| **Go** | ≥ 40 % разговоров: конкретный случай проблемы с ночёвкой в пути (искали на ходу, приехали поздно, переплатили, отказали, пришлось ехать дальше, чем хотели) |
| **Adjust** | Проблема есть, но про другое: например, только поиск жилья в точке назначения, или про темп и усталость, а не про место ночёвки |
| **Drop** | < 20 % разговоров с конкретным случаем, или большинство ночует только в точке назначения и не останавливается в пути |
| Также смотрим | Сколько поездок вообще имели ночёвку в пути; как решали, сколько ехать в день |

# Дата-рум Версты: оглавление (INV-01)

26.10.2026 · Business Analyst (владелец оглавления) + CEO · обновлять каждую пятницу до M6 (W13, 18–24.01.2027)

> **Статус.** Дата-рум собирается. Из восьми пунктов приёмки INV-01 готовых нет. Три есть в черновике: юнит-экономика и план использования средств (модели на допущениях, 0 измеренных значений) и разбор конкурентов (без теста CEO). Остальные пять — «будет после …» (сводка в разделе 1). Ни одна строка не заполняется выдуманными данными: пустое значит пустое.

**Правила.**

1. **Одна папка.** Инвестор получает одну папку с этим оглавлением наверху. Ссылки ниже указаны относительно `docs/investor/`.
2. **Репозиторий публичный** (D-IR-07). Устав, свидетельство о регистрации, таблицу долей, договоры, счета и всё с персональными данными в репозиторий **не кладём**. Они живут в закрытой папке, место выбирает CEO. Здесь для них только строка указателя с пометкой «закрытая папка».
3. **Персональные данные — только обезличенно.** Интервью и бета показываем только сводками, без имён и контактов (152-ФЗ, `docs/traction/interviews.md`).
4. **Статус в каждой строке:**
   - «готово» — документ есть и не требует данных, которых ещё нет;
   - «черновик» — документ есть, ждёт ревью или решения;
   - «есть план, нет данных» — метод готов, чисел ещё нет;
   - «будет после …» — документа нет, указано, что его откроет;
   - «не начато».
5. **У каждого числа есть статус.** В документах с моделями у каждого числа есть статус «допущение / источник / измерено». Перед встречей «измерено» должно стоять у всех строк таблицы целей.

# 5.7 Exit to overnight («Съезд к ночёвке»)

Mockup: `docs/design-canvas/Exit.dc.html` · Behaviour: SPEC 5.7, 10, 14 · Components: §8, §9, §10, §12, §14, §15, §16

## 1. Layout rules
- Root fill `color.dash.base`. Night scene 0–430 top-anchored; dashboard top 410 (height 434) bottom-anchored. The navi panel stretches between top 54 and bottom 98 of the dashboard; the hotel list scrolls inside it when there are 3 options or the font is scaled.
- Short windows: the scene shrinks first (min 300 dp of scene, k = (dashTop + 20) / 430); below that the panel scrolls.

## 3. Copy

| Slot | Copy |
| --- | --- |
| Header | «НОЧЁВКА <k> ИЗ <n>» · «КМ <kmAt> · <HH:mm arrival>» |
| Reason | server reason string (SPEC 7.5), e.g. «Не в Ростове, а на 55 км дальше: тут больше отелей с собакой, а вечером можно дойти до Стрелки. Ваши 300 км в день не превышены.» |
| Hotel name | name or district: «У Стрелки, в центре», «У въезда с трассы» |
| Tags | from the closed tag list, joined by « · »: «можно с собакой · семейный номер · парковка»; tag labels: `dogs_allowed` «можно с собакой», `family_room` «семейный номер», `parking` «парковка», `parking_guarded` «охраняемая парковка». The mockup's «машина под окном» is not in the closed tag list (OI-30) |
| Price | «≈ 6 000 ₽» per night for the whole crew |
| CTA | «Забронировать ночь» / «через Яндекс Путешествия» |
| Exit sign | «<Town>» / «центр»; distance «800 м» |

## 4. States

| State | Visual / copy |
| --- | --- |
| Default | as the mockup, option 1 selected (the engine's choice) |
| 3 options | third `HotelOption` at y 736.4 — the panel content scrolls (8 dp fade at the panel bottom edge, `color.navi.screen`) |
| Creating the link (`GET /v1/links/hotel`, ≤ 1.5 s) | CTA arrow replaced by a 20 dp ring spinner (stroke 2.6, `color.text.onLight`, 270° arc rotating 900 ms linear); CTA not pressable |
| Link error / timeout | toast «Не получилось открыть бронирование. Попробуйте ещё раз» |
| Offline | `BookCta` offline state (components §15): title «Забронировать ночь» `color.text.secondary`, sub «Нужен интернет» `color.accent.redText`; panel header right gains `OfflinePlate`; hotels stay selectable |
| Return from the partner (`onResume` after the link opened) | `NaviDialog`: title «Забронировали?», body «Отметим ночёвку в Ярославле как забронированную», primary «Да, забронировали», secondary «Ещё нет». Yes → option in the booked state; Road ahead hotel row shows «Забронировано ✓»; dialog not shown again for this night |
| Booked | selected option shows «забронировано» instead of the price; CTA becomes `SecondaryButton` style «Открыть бронирование» (re-opens the partner link) |
| `NO_LODGING` | a warning row above the hotels: «!» badge + «Не нашли ночёвку с вашими условиями — показали ближайшую подходящую» `type.body.sm` `color.text.primary`; the reason sentence still shows |
| Unverified hotel | tags line starts «не проверено · …» |

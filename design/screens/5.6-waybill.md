# 5.6 Waybill («Путевой лист») — cost

Mockup: `docs/design-canvas/Waybill.dc.html` · Behaviour: SPEC 5.6, 8, 14 · Components: §11, §14, §15, §16

## 1. Layout rules
- Root fill `color.dash.raised`, padding 14 14 20 (mockup). No scene (the sheet sits on the dashboard).
- The two buttons are **pinned** at bottom 20 (mockup `margin-top: auto`). Everything above them (back link, sheet, Pro plate) is one vertical scroll; at 844 with the reference data it fits without scrolling. Expanding a cost line can make it scroll; the expanded line is then scrolled into view (`bringIntoView`).
- Horizontal: sheet L14/R14; buttons two equal columns, gap 10.

## 3. States

| State | Visual / copy |
| --- | --- |
| Default | as the mockup; reserve on |
| Reserve off | checkbox empty; reserve sum «—»; total and left recomputed ≤ 100 ms (SPEC US-10), the changed handwritten values cross-fade 200 ms |
| Line expanded | chevron rotated 180°; breakdown rows below the formula (components §11). Examples: fuel — «Московская обл. · 210 км × 62,40 ₽» / «1 050»; lodging — «7 нояб. · Ярославль, «У Стрелки»» / «6 000» |
| Over budget | «Остаток» label → «Перерасход»; value «2 300» in `color.paper.inkRed` (no minus sign; the label carries the meaning); a hint line below P9: «Дешевле: другая ночёвка, меньше музеев или «Просто доехать»» `type.paper.label` `color.paper.text`, margin-top 4 |
| Budget «не важно» | «Выдано» value «—», «Остаток» value «—» |
| Real data wired | footnote prefix «Расчёт:» instead of «Пример расчёта:» (SPEC 5.6) |
| Saved | K1 → «Сохранено ✓» (check drawn), disabled look (text `color.text.secondary`), no press |
| Offline | everything works (local recompute); K2 shares plain text |
| Recompute pending (PATCH in flight) | no spinner; values are local-first. If PATCH fails: toast «Не удалось синхронизировать расчёт — повторим позже» |
| Pro plate pressed | fill `color.dash.pressed` |

### 3.1 Stamp behaviour
Plays (`motion.stamp`) the first time the Waybill opens for a trip version; later openings show the final frame. Any cost change after it has played does not replay it.

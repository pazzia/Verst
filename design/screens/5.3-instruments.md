## 1. Layout rules

- Root fill `color.dash.raised`. The strip (0–120) and the mirror are top-anchored. The caption + start row is bottom-anchored (bottom 24).
- Between the summary line and the caption row is a vertical **scroll region** (y 322 … caption top − 15). At 844 everything fits without scrolling. On shorter windows the wells, mood chips and settings plate scroll under a 16 dp fade (`color.dash.raised` alpha 0 → 1) above the caption row.
- Horizontal: mirror L20/R20; wells L14/R14, two equal columns, gap 12.

## 3. Logic and copy

| Item | Rule / copy |
| --- | --- |
| Seat cycle | empty → adult → child → empty. Limit (decisions.md OI-07): adults + children ≤ 8 including the driver, adults ≥ 1 (the driver). With the third row every seat can be filled, so the limit is the seat count |
| More than 3 back passengers | OI-07: a «+ третий ряд» link (`type.body.mdStrong` `color.accent.yellow`, 44 touch) under the hint row adds a second bench of 3 seats in the mirror (mirror height 174 → 252: bench 2 at y 223, seats at y 229); the hint row and everything below move down by 78 |
| Summary | «<A> взросл(ый/ых)» + « · <C> ребён(ок/ка) / детей» + « · собака»; ICU plurals (SPEC 16) |
| Odometer | 150–900, step 50; default 300 if the trip is < 800 km, 500 otherwise |
| Read-out line 1 | «≈ <h> ч <m> мин за рулём»; minutes rounded to 10, «мин» omitted when 0 («≈ 4 ч за рулём») |
| Read-out line 2 | round trip: «<N> дн(я/ей) на кольцо»; one-way: «<N> дн(я/ей) в пути»; N = ceil(km / daily km) |
| Budget presets | «до 20 000 ₽» «до 30 000 ₽» «до 40 000 ₽» «до 60 000 ₽» «до 80 000 ₽» «не важно» |
| Caption label | «ВСЁ ГОТОВО К ВЫЕЗДУ» |
| Caption meta | ready route: «из Москвы · 745 км по кругу»; free trip: «≈ 265 км · 1 заезд» |

## 4. States

### 4.1 Default — as the mockup (crew from the user's saved defaults).
### 4.2 Limits reached — the next seat state that breaks a limit is skipped; when nothing can be added, empty seats show the disabled state «нет мест» and a tap shows the toast «В машине до 8 человек вместе с вами».
### 4.3 Key limits — at 150 the odometer «−» is disabled; at 900 «+» is disabled; budget «−» disabled at 20 000, «+» disabled at «не важно».
### 4.4 Offline — no visual change (all local). ПОЕХАЛИ stays enabled; Drive shows its offline state.
### 4.5 Settings plate and sheet (NEW)
Plate: fill `color.dash.controlAlt`, radius `radius.r10`, padding 0 12; gear icon 18 (§17.4, stroke 2, `color.text.secondary`), gap 10, «Машина и выезд» `type.body.mdStrong` `color.text.primary`, flex; summary «АИ-95 · 8,0 л · сб 08:00» `type.body.sm` `color.text.secondary`; chevron (`right` arrow 14, stroke 2.5). Pressed: `color.dash.pressed`. TalkBack: «Машина и выезд: АИ-95, расход 8 литров, выезд в субботу в 8:00. Изменить».
Sheet: open-issues D-4.
### 4.6 Mood
Default: «Спокойно, с детьми» is pre-selected when children > 0 (SPEC 7.1 `calm`). With no children nothing is pre-selected and `mood` is omitted from the request, so the server default applies; the Manager must confirm that default (OI-08). Single select; tapping the selected chip deselects it.
### 4.7 Loading / error — none on this screen (no network). The plan request is made on Drive.

## 5. Interactions and transitions

| Trigger | Result | Transition |
| --- | --- | --- |
| Seat | cycle state, update summary | `motion.selection` on the seat |
| Dog | toggle, wag starts/stops | instant + `motion.dogWag` |
| Front chip | toggle | `motion.selection` |
| − / + | change value | `motion.odometerRoll` / `motion.needle` |
| Mood chip | select | `motion.selection` |
| Settings plate | settings sheet | `motion.bottomSheetIn` |
| ПОЕХАЛИ | Drive 5.4; `POST /v1/trips/plan` | `motion.screen.launch` |
| Back link / system back | previous screen (Windshield or Navigator); values are kept as defaults | `motion.screen.back` |

All values persist to DataStore on change (SPEC 5.3).

## 6. Animation timeline
Loops: dog wag (when the dog is on), start pulse. Events: odometer roll 300 ms per change; needle spring per change. Reduced motion: no wag, no pulse, instant digit swap, needle snaps.

# 5.1 Windshield («Лобовое стекло») — home

Mockup: `docs/design-canvas/Wind.dc.html` · Behaviour: SPEC 5.1, 13 · Components: `components.md` §1, §3.1, §7, §8, §9, §10, §16

## 1. Layout rules

- Reference window 390 × 844 dp (below the status bar, above the navigation bar). Root fill `color.dash.base`.
- **Two anchor groups.** Group T (scene, mirror, overhead sign) is anchored to the window top. Group B (dashboard and its content) is anchored to the window bottom: dashboard height = **324** (844 − 520) at every window height.
- Horizontal constraints are given as `L/R` insets (the element stretches with the width) or `C` (centred, fixed width). Valid widths: 360–480 dp.
- Short windows: the scene height = window height − 324 + 20 (it runs 20 dp under the dashboard curve). The overhead sign shows `rows = clamp(floor((dashTop − 8 − 84 − 58) / 44), 2, 4)` rows, where 58 = 12 + 18 + 18 + 10 is the fixed plate overhead. At 844 → 4 rows. The selected row is always among the visible rows (§4.2). Scene y-values (bands, horizon, road) scale by k = min(1, (dashTop + 20) / 540); x-values scale by W / 390.

## 4. States

### 4.1 Default (success) — as the mockup; row 1 selected on first load.

### 4.2 Row selection
Tap a row → it becomes selected (`motion.selection`, 200 ms cross-fade), the caption updates instantly (title + meta), the polite live region announces «Выбран маршрут: Ярославль, 265 километров». When a route is picked from the full-list sheet (§4.6) and is not among the visible rows, it is moved to row 1 and the others shift down.

### 4.3 Loading (≤ 2 s; skeleton never shown for < 300 ms — if data arrives within 300 ms, skip the skeleton)
- Sign: header shows «РЯДОМ С ВАМИ · ИЗ МОСКВЫ» (the start is resolved first); 4 placeholder rows (components §1.1 "loading") with shimmer; the footer is hidden.
- Caption: label «ВЫБРАН МАРШРУТ»; title placeholder plate 160 × 20, meta plate 120 × 12, fill `color.dash.controlAlt`, radius 4, shimmer `color.dash.outline`.
- Start button: disabled.
- Navigator panel: fully interactive.
- TalkBack: the sign has the content description «Загружаем маршруты рядом».

### 4.4 Saved trips present — «Мои поездки» plate
Plate: h 36, padding 0 12, radius `radius.r8`, border `stroke.w1` `color.dash.outline`, fill transparent; bookmark icon (components §17.4) 16 × 16 stroke 2 `color.text.secondary`, gap 6, «Мои поездки · 3» `type.body.mdStrong` `color.text.secondary`. Pressed: fill `color.dash.pressed`, text `color.text.primary`.
Caption layout with the plate: the caption column becomes label / title / meta / 8 gap / plate (total 101.2); it stays vertically centred on the start button, so the label moves to y 691.4 and the plate sits at y 757.
TalkBack: «Мои поездки, 3 сохранённые. Открыть список».
Tap → «Мои поездки» sheet (open-issues OI-20, design D-1).

### 4.5 Offline
- **With cached ready routes:** the rows render as default. Sign header right «КМ» → offline icon 11 + «НЕТ СЕТИ» (`color.sign.blueText`). Navi header left «НАВИГАТОР · » followed by the `OfflinePlate` (offline icon + «НЕТ СЕТИ», `color.accent.redText`); D5 «ВЫ:» stays. Field sub → «без сети открываются только сохранённые поездки». The start button stays enabled (the plan request goes to the Drive offline state).
- **Without cache:** the sign shows header + one message block instead of rows: text «Нет сети — готовые маршруты появятся, когда будет интернет», `type.title.sm`, `color.sign.white`, padding 10 6, up to 3 lines. Footer hidden. Caption: label «НЕТ СЕТИ», title «Мои поездки работают» (if saved trips exist; one line at 22 sp) or «Подключитесь к интернету», meta «маршрут построим, когда появится сеть». Start disabled.
- Network comes back: rows load with the loading → default transition (no toast).

### 4.7 No ready routes near the start
- Sign: header + message «Рядом пока нет готовых маршрутов» (`type.sign.lg`, `color.sign.white`, padding 10 6) + footer line «Наберите любой город в навигаторе ↓» (`type.caption.md`, not a button).
- Navi field highlighted: border `stroke.w2` `color.accent.yellow`; the border alpha pulses 1 → 0.4 → 1 twice (2 × 1200 ms, `easing.easeInOut`) on first display, then stays solid. Reduced motion: solid border.
- Caption: label «КУДА ЕДЕМ?», title «Выберите в навигаторе», meta «город, адрес или точка на карте». Start disabled.

### 4.8 Error (ready-routes request failed while online)
Sign message block: «Не получилось загрузить маршруты» + a row button «Повторить» (`type.sign.lg`, `color.accent.yellow`, 44 high, arrow `right`). Caption as 4.7. TalkBack: «Не получилось загрузить маршруты. Повторить, кнопка».

### 4.8a Engine starting / failed (mock build, open-issues D-15)
See open-issues D-15: `engine-starting` = §4.3 loading (or cached rows at once); `engine-failed` = the §4.8 error layout with `engine_failed_title` / `engine_failed_text` / `common_retry`.

### 4.9 Location permission (first launch) — not shown in the mock build (D-16)
- First launch only: a `PlateToast` 16 dp above the start button (y 664 bottom edge, x L18/R18): «Определим город старта, чтобы показать маршруты рядом» + action «Разрешить». It stays until acted on or until the user taps anything else (then dismissed for good). «Разрешить» → system dialog (coarse location).
- Tap D5 «ВЫ: МОСКВА» → if not granted: system dialog directly (the user expressed intent); if permanently denied: toast «Доступ к геопозиции выключен в настройках» + action «Настройки».
- Denied → toast «Хорошо, старт — Москва. Изменить можно в навигаторе» (3 s).
- While resolving the location: D5 text «ВЫ: …» with the locate icon at 50 % alpha blinking 600 ms; ≤ 1.5 s, then fall back to the last start.

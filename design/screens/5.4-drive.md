## 3. Data mapping

| SSE event | UI |
| --- | --- |
| request sent | header «СТРОИМ ДОРОГУ · <km> КМ» (km = template km or straight-line «≈ 265 КМ»), right slot empty; bar 0; scene accelerates (§6) |
| `stage {key, text}` | previous active line → done (check); new line appended as active (ring + «…»); bar → stage index / 5 (`split` 1, `lodging` 2, `hours` 3, `fuel` 4, `cost` 5) over `motion.progress`. After `split` the header right shows «<N> ДН(Я/ЕЙ)» |
| `stop {day, stop}` | a flying sign of the stop's variant is queued (§2.2); sign text = town name + kind word or km |
| `done {tripId}` | last line → done; bar 100 %; CTA appears (`motion.ctaAppear`); auto-advance to Road ahead after 1000 ms (not when TalkBack is on, §4.1) |
| `error {code}` | §4.4 |

Step copy comes from the server `text` (templates in backend config). Mockup copy for reference: «Делим кольцо на 3 дня по ≈ 250 км» (mockup «~250», fixed to «≈» per SPEC 5), «Ищем отели, куда пустят с собакой», «Сверяем, когда открыты кремли и музеи», «Считаем бензин: 8 л на 100 км».

## 4. States

### 4.1 Success
CTA shown, auto-advance 1 s. With TalkBack on: no auto-advance; announce «Дорога готова. Смотреть знаки, кнопка» and keep focus on the CTA (OI-25).

### 4.2 Slow (20 s without `done`)
New line (active style) «Строим дольше обычного…». The CTA area shows two buttons, each (354 − 10) / 2 = 172 × 58, gap 10: left «Подождать» (`SecondaryButton`), right «Упростить маршрут» (`YellowButton`, `type.cta.md`). «Подождать» hides the buttons for another 20 s. «Упростить маршрут» cancels and re-sends the request without sights (SPEC 5.4); the steps list is cleared and restarts.

### 4.3 Warning `NO_LODGING` (trip still returned)
A step line with a yellow «!» (12 × 12 circle `color.accent.yellow`, «!» `type.caption.bold` `color.text.onLight`) and the text «Не нашли ночёвку с вашими условиями — показали ближайшую подходящую» (2 lines allowed). The flow continues to success.

### 4.4 Error
Scene: lane speed eases from drive to idle (450 → 900 ms period over 800 ms, `easing.decelerate`); no new flying signs; signs in flight finish their path.
Panel: header left «НЕ ПОЛУЧИЛОСЬ», right empty; no bar; message `type.body.step` `color.text.primary` from the SPEC 12 table, then the sub-line «Параметры поездки сохранены — можно попробовать ещё раз.» `type.body.md` `color.navi.text`. The back link changes from «Отменить» to «Приборы» (nothing is left to cancel). CTA by code:

| Code | Message | CTA |
| --- | --- | --- |
| `UPSTREAM`, network timeout | «Сервис маршрутов временно недоступен» | «Попробовать ещё раз» (re-send) |
| `INVALID_INPUT` | «Проверьте параметры поездки» | «К приборам» (back to 5.3) |
| `UNREACHABLE` | «Не нашли дорогу на машине до этой точки» | «Изменить маршрут» (back to 5.2, error in the caption) |
| `TOO_SHORT` | «Слишком близко для поездки на машине» | «Изменить маршрут» |
| `RATE_LIMITED` | «Слишком много запросов, подождите минуту» | disabled CTA «Попробовать через 0:59», counting down each second; enabled at 0 as «Попробовать ещё раз» |

### 4.5 Offline (no network at send time)
Header «НЕТ СЕТИ» (`OfflinePlate`, red); message «Чтобы построить дорогу, нужен интернет.» + sub-line «Сохранённые поездки открываются без сети — на лобовом, в «Мои поездки».»; back link «Приборы»; CTA «Попробовать ещё раз». The road runs at idle speed.

### 4.6 Cancel
«Отменить» or system back: cancel the request (close the SSE stream), return to Instruments with all values kept. No confirmation.

## 6. Animation timeline (success path; times measured from screen entry)

| t (ms) | Event |
| --- | --- |
| 0 | cross-fade in; lanes ramp to 450 ms period by t = 800; posts start (left offset 550) |
| ≤ 1000 | first `stage` (SPEC 16 target): line 1 appears (`motion.stepAppear`, 350 ms), bar → 20 % |
| per event | next lines no closer than 400 ms apart (`motion.stepAppear.minGapMs`; events that arrive faster are queued) |
| per `stop` | a flying sign spawns; consecutive signs ≥ 1200 ms apart; alternate right / left (first right); at most 3 in flight |
| `done` | bar → 100 % (400 ms), then the CTA appears (350 ms) |
| `done` + 1000 | auto-advance |

Mockup reference timeline (static demo, not data): steps at 300 / 1100 / 1900 / 2700 ms, bar 0 → 100 % over 3400 ms starting at 200 ms, CTA at 3400 ms. These are the Paparazzi demo values for the screenshot test with a fake stream.

Reduced motion: road static, posts hidden, no flying signs (instead, the most recent stop's sign is shown static at the spawn point at scale 1.0), lines appear instantly, bar jumps, CTA instant; auto-advance stays.

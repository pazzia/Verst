# 5.13 Hand-off to Яндекс Навигатор / Яндекс Карты (Sprint 3, DES-305)

Mockups: menus in `docs/design-canvas/Handoff.dc.html`; the walk button in `WalkResult.dc.html` · Behaviour: CEO (4), Manager D7, **ADR-0014** (`handoff`) · Components: §16, §22 · Copy: copy-ru §15.5 — the only brand-bearing keys (`handoff_*`)

## 1. Where

| Place | Control | Engine call |
| --- | --- | --- |
| 5.5 day header | the existing link «в навигатор ↗» now opens the **day menu** (`BottomSheet`, small): title «День 2», item `handoff_day` «В навигатор: день 2», under it the target line | `mode = car, day = N, fromHere = true` |
| 5.5 stop menu (D-5, long-press a row) | first item `handoff_from_stop` «Открыть в навигаторе отсюда» (replaces `stopmenu_navigator`), then «Заменить», «Сообщить об ошибке» | `mode = car, fromStopId = <row>` |
| 5.11 walk result | `SecondaryButton` «Пешком в Яндекс Картах» under the chips; one per part when split | `mode = walk` |

Fuel and rest stops are never hand-off origins (not tappable, but long-press keeps D-5 for them; the engine drops fuel/rest as points).

## 2. Labels tell the truth before the tap

The app resolves the target once per screen (`PackageManager`, `<queries>`): car navigator → maps → web; walk maps → web. The menu item / button label is chosen from that:

| Resolved | Car label | Walk label | TalkBack |
| --- | --- | --- | --- |
| Яндекс Навигатор | «В навигатор: день 2» + target line `handoff_navigator` «Открыть в Яндекс Навигаторе» | — | `handoff_cd_navigator` |
| Яндекс Карты only | target line `handoff_maps_car` «Открыть в Яндекс Картах» | «Пешком в Яндекс Картах» | `handoff_cd_maps_walk` |
| nothing | target line `handoff_web` «Открыть Яндекс Карты в браузере» | «Открыть Яндекс Карты в браузере» | `handoff_cd_web` |

Target line: `type.body.sm` `color.text.muted`, under the item. When `truncated = true`: an extra line `handoff_truncated` «Навигатор принимает до 8 промежуточных точек — взяли главные» `type.body.sm` `color.accent.yellow`.

## 3. Behaviour

- One tap opens the target; **no chooser, no 2GIS** (ADR-0014). An `ActivityNotFoundException` falls through to the next link; after a web fallback the toast `handoff_toast_web` / `handoff_toast_web_walk` (3 s).
- Offline + no app: the item keeps its look; a tap shows `handoff_offline`. An installed app opens offline.
- Failure of all links: toast `handoff_failed`.
- Back from the app: focus returns to the row (5.9 §5).

## 4. Brand rule

Only `handoff_*` keys contain «Яндекс». The old `stopmenu_yandex_*`, `stopmenu_2gis`, `stopmenu_install`, `exit_book_partner`, `cd_exit_book` stay unused. Everything else, including every TalkBack string outside `handoff_*`, is brand-free.

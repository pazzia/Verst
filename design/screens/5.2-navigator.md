# 5.2 Navigator («Навигатор») — any A → any B

Mockup: `docs/design-canvas/Navi.dc.html` · Behaviour: SPEC 5.2, 10, 12 · Components: §8, §7 (S), §9, §10, §14, §16

## 1. Layout rules

- Root fill `color.dash.base`. Scene strip 0–150 is top-anchored. The dashboard starts at y 132.
- The navigator panel is stretched between top 188 and bottom inset 140 (mockup `top: 56; bottom: 140` inside the dashboard). Its content **scrolls inside the panel** (the mockup clips it with `overflow: hidden`, which hides results — OI-21).
- The route caption + start button are bottom-anchored (bottom 26).
- **Keyboard (IME) open** (КУДА is focused on open, so this is the normal state): the caption + start row hides (fade 150 ms); the panel bottom = IME top − 12; the panel content scrolls. The row comes back when the IME closes (a suggestion is picked or the user presses back once). This is not in the mockup (OI-22).
- Horizontal: L/R constraints as in the table.

## 3. Panel content by state

The order inside the panel is always: header → ОТКУДА → [vias] → КУДА → *dynamic block* → dashed buttons → *secondary block*.

| Query state | Dynamic block | Secondary block |
| --- | --- | --- |
| Empty or < 2 characters, recents exist | — | label «НЕДАВНО ИСКАЛИ» + up to 10 recent rows (`SuggestionRow` with a clock icon in the badge slot: badge fill `color.navi.field`, icon `clock` 16 `color.navi.text`). Rows show «Москва → Ярославль» as name and the date «вчера», «12 октября» as sub |
| Empty, no recents | — | label «ЧАСТО ИЩУТ» + chips from remote config («Петербург → Выборг», «Екатеринбург → Пермь», «Краснодар → Абрау-Дюрсо») |
| ≥ 2 characters, waiting (> 250 ms debounce + request) | 3 skeleton rows: badge plate 26 × 26, name plate 140 × 12, sub plate 90 × 10; fill `color.navi.field`, shimmer `color.navi.listSelected` | hidden |
| Results | up to 6 rows (mockup shows 4) | hidden |
| No results | one block, padding 12, fill `color.navi.list`, radius 10: «Ничего не нашли по запросу «<q>»» `type.list.title` + «Попробуйте иначе или поставьте точку на карте» `type.body.sm` `color.navi.labelSecondary`. The «точка на карте» button gets a 2 dp yellow dashed border | hidden |
| Suggest error / timeout 1.5 s | block: «Подсказки не загрузились» + link button «Повторить» `type.body.mdStrong` `color.accent.yellow` (44 touch) | recents |
| Offline | block: offline icon 16 + «Поиск работает только с интернетом» `type.list.title` + «Сохранённые поездки открываются на лобовом — «Мои поездки»» `type.body.sm`. The header right «GPS ●» is replaced by `OfflinePlate` «НЕТ СЕТИ» | recents (tappable: they fill A and B) |

Suggestion row content: badge Г (город, `color.sign.blue`), У (улица, `color.navi.fieldBorder`), М (место, `color.sign.brown`); name; sub «<type> · <region>» («город · Ярославская область»); km = straight-line distance from A, «≈ 265 км» (OI-23: the mockup shows the number without «≈»); thin-space thousands («1 230 км»).

## 4. States and flows

### 4.1 Open
КУДА focused, IME open, caption row hidden. If the user came from the Windshield with a selected ready route, КУДА stays empty (the ready route is not a B).

### 4.2 Pick a suggestion
Row → selected fill (`color.navi.listSelected`, 200 ms), КУДА value = name, IME closes, caption row fades in (150 ms): title «Москва → Ярославль», meta «≈ 265 км · город · Ярославская область». Start enabled.

### 4.3 No B yet
Caption: title «Москва → ?», meta «выберите, куда ехать». Start disabled (components §7).

### 4.4 Validation (after B is set)
- Straight-line distance < 15 km on the device → meta «Слишком близко для поездки на машине» in `color.accent.redText`, start disabled.
- Server `TOO_SHORT` / `UNREACHABLE` (returned by the plan call) brings the user back here from Drive with the meta text «Слишком близко для поездки на машине» / «Не нашли дорогу на машине до этой точки» in `color.accent.redText`, and КУДА focused.

### 4.5 Change A («изменить»)
ОТКУДА turns into an editable `NaviInput` (yellow round marker), КУДА collapses to a value field. The dynamic block's first row is «Моё местоположение» (badge with the `locate` icon, fill `color.navi.field`). Tapping it starts the location flow (5.1 §4.9). Picking a row returns ОТКУДА to a value field with «изменить».

### 4.6 Vias («+ заехать по пути», up to 3)
```
┌ ОТКУДА  Москва · вы здесь                    [изменить] ┐
├ ≡ ● ЗАЕЗД 1  Ростов Великий                         [×] ┤  NaviValueField, min-h 50
├ ≡ ● ЗАЕЗД 2  | Начните вводить                     [×] ┤  NaviInput while typing
├ ■ КУДА — город, адрес, место  Ярославль                 ┤
```
- The via field is inserted above КУДА and focused. Leading: drag handle (`dragHandle` 16, `color.navi.labelSecondary`, touch 44 × 50), then a filled circle d 10 `color.navi.label`. Caption «ЗАЕЗД <n>». Trailing «×» (`close` 16, touch 44).
- Reorder: long-press the handle → the field lifts (fill `color.navi.listSelected`, shadow `shadow.signMd`), drag; the others slide 200 ms. TalkBack custom actions «Переместить выше» / «Переместить ниже».
- When 3 vias exist, D10 is disabled with text «максимум 3 заезда».
- Caption title with vias: «Москва → Ростов → Ярославль» (ellipsis in the middle).

## 5. Interactions and transitions

| Trigger | Result | Transition |
| --- | --- | --- |
| Back link / system back (IME closed) | Windshield | reverse of `motion.screen.zoomToNavi` |
| System back with IME open | closes the IME only | system |
| Suggestion / recent / chip | sets B (a chip or recent sets A and B) | `motion.selection` |
| ПОЕХАЛИ | Instruments 5.3 with A, vias, B | `motion.screen.lookAtMirror` (the large mirror grows from the top centre) |
| точка на карте | Map picker | `motion.screen.overlay` |

## 6. Animation timeline
Loops: lane dashes (1400 ms), start pulse (1800 ms, spread 14 dp), text cursor blink (`motion.caret`, the native `BasicTextField` cursor in `color.accent.yellow`). No timeline events. Reduced motion: dashes static, no pulse, cursor steady (no blink).
